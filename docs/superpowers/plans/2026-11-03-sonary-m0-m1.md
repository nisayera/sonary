# Sonary M0 (Fundament) + M1 (Systemmonitor) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eine lauffähige Menüleisten-App „Sonary" mit Modulsystem und Liquid-Glass-Design-System, deren erstes Modul ein Systemmonitor (CPU, GPU, RAM, Netzwerk, Disk, Akku, Temperaturen, Verlauf, Menüleisten-Anzeige, Warnungen) ist.

**Architecture:** Ein Xcode-Projekt (erzeugt aus `project.yml` via XcodeGen) bindet lokale Swift-Packages ein: `SonaryCore` (Modulsystem, Berechtigungen), `SonaryUI` (Design-System), `Monitor` (Sampler, Quellen, UI). Alle Hardware-Quellen stehen hinter Protokollen; Berechnungen sind reine Funktionen und werden mit Fakes getestet.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI, Observation, Swift Charts, Swift Testing, IOKit/IOReport, UserNotifications, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-11-03-sonary-design.md`

## Global Constraints

- macOS 26 (Tahoe) als Deployment Target, nur Apple Silicon (`ARCHS = arm64`); kein `#available`-Fallback.
- Swift 6 language mode, strict concurrency; null Compiler-Warnungen; keine Force-Unwraps im Produktivcode.
- Lizenz GPL-3.0-or-later; jede aus Vorssaint übernommene Datei wird in `NOTICE` mit Herkunft vermerkt; Name/Logo/Look von Vorssaint nicht übernehmen.
- Glass (`.glassEffect()` / `GlassEffectContainer`) nur für schwebende Elemente; 8-pt-Raster; SF Symbols; Federanimationen < 500 ms; Reduce Motion → Opacity-Fade; Reduce Transparency respektiert; VoiceOver-Labels; Dark Mode.
- UI-Sprachen Englisch + Deutsch (`Localizable.xcstrings`).
- Keine Berechtigungen für M1; Berechtigungen werden nur beim Aktivieren eines Moduls angefragt.
- Tests mit Swift Testing; Datenquellen hinter Protokollen.
- **Build-/Testbefehle laufen auf macOS mit Xcode 26** (die Linux-Umgebung dieser Sitzung kann nicht bauen).

## Review Focus

1. Mac ohne Akku (z. B. Mac mini): `battery == nil`, Akku-Karte wird ausgeblendet, kein Absturz.
2. Sensor nicht lesbar (IOReport/HID liefert nichts): GPU/Temperatur zeigen „—", Rest läuft weiter.
3. Zähler springen zurück (Netzwerk nach Sleep/Interface-Wechsel): Raten sind nie negativ.
4. Identische CPU-Ticks bzw. Intervall 0 (erster Sample): Auslastung ist 0, nie NaN/∞.
5. `start()` eines Moduls wirft: Modul wird deaktiviert, Fehlertext gespeichert, App und andere Module laufen weiter.
